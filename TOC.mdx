**Introduction.**

AWS provides a range of services focused on Security and Compliance to
help customers protect their data, applications, and infrastructure in
the cloud. Both AWS and Customer shares responsibility for handling
Security and Compliance.

In Today's Digital world, Security is very essential. Throughout
real-world IT industry ,cloud infrastructure empower the security and
compliance through different AWS services such as AWS Identity and
Access Management (IAM), AWS WAF, AWS Cognito and many more.

For the AWS Security, AWS provide safe environment for the On-Premises
Data Centers as well as in the Cloud. It Create the controlled
environment so that the Data doesn't get leaked or Hacked. And the
Compliance ensure the proper use of Security Practices and a variety of
IT security standards.
